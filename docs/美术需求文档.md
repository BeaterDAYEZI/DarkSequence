# 《暗蚀牌序》美术资源需求文档

> 版本：v1.0（2026-08-24）｜ 基准分辨率：**1920×1080（16:9）**，横屏网页游戏
> 风格：维多利亚工业哥特 · 黑暗幻想 · 幽灵列车
> 主色调：暗黑铸铁（#0a0a0e/#1a1a24）、暗金（#c9a227）、锈红（#8c2f2f）、蚀蓝（#2f4a8c）
> 输出格式：PNG（带透明通道）为主，图标可用 SVG；单张文件 < 1MB，优先 Web 优化

## 三、按界面拆分的需求

### 3.1 标题画面
- **背景图**：蚀雾中的幽灵铁轨全景，列车的车灯在雾中投射光柱（氛围用，前景 UI 覆盖）
- **标题 LOGO**：《暗蚀牌序》四个大字（暗金描边，工业哥特字体，透明底 PNG）
- 按钮：开始旅程 / 继续旅程 / 试玩战斗 / 音效开关（UI 组件即可，无需单独美术）

### 3.2 战斗界面（核心场景）
布局（左主战场 + 右 300px 日志栏）：
```
┌──────────────────────────────┬──────────┐
│ 顶栏：魂火/能量/暗蚀/区域/压力表 │ 战斗日志  │
├──────────────────────────────┤          │
│ 敌方队列（4格，Boss带推进轨道）   │ 滚动列表  │
│ 铁轨中线                        │          │
│ 车厢×4（英雄站在车顶）           │          │
├──────────────────────────────┤          │
│ 牌序规划槽 + 魂火服务按钮         │          │
│ 手牌区（至多7张可滚动）           │          │
└──────────────────────────────┴──────────┘
```
需要的美术：
- **车厢顶部**（4 张，横向 800×400）：锈蚀铁板+符文锁链，编号灯（1-4）
- **英雄站位**：头像即可，不需全身（头像+血条+狂气灯）
- **敌人**：每只一个立绘卡，带意图图标区
- **Boss 推进轨道**：车头→车尾的横向轨道条
- **手牌**：卡牌牌面（见卡牌规范）
- **压力表**：SVG 矢量表盘（指针动画），或导出静态表盘 PNG + 代码旋转指针

### 3.3 地图界面（幽灵铁轨）
- **背景**：当前区域的主题俯视（5 区域：枯黄平原/蚀雾沼泽/灰烬隘口/断桥深渊/星蚀山麓）——每区域 1 张 1920×1080 平视背景
- **铁轨**：竖向平铺，岔道分叉（左轨暗红/右轨暗蓝）
- **节点图标**（128×128）：遭遇战⚔️/精英💀/事件❓/调度站🏚️/岔道🔀/Boss👑/起点🚂——现在的 emoji 全部替换为美术图标
- **列车位置指示**：小列车图标（车头朝上）标记当前节点

### 3.4 营地界面
- 背景沿用区域背景；英雄立绘半身图（灌注/复活时展示）

### 3.5 结算界面
- 胜利/败北背景各 1 张（氛围图）
- 英雄头像列

## 四、卡牌美术规范（最重要）

### 4.1 卡牌结构（500×700）
```
┌─────────────────────┐
│ ◈  品质框/边框        │ ← 四品质：白/绿/蓝/橙（代码用边框色实现，美术出底框+角标）
│ ◇ 费用角标(左上)     │
│   ┌─────────────┐   │
│   │   插画区      │   │ ← 500×320，内容透明底
│   └─────────────┘   │
│   牌名（中部）        │
│   效果文字区（底部）   │ ← 代码渲染文字，美术留空
└─────────────────────┘
```
- **牌面底框**：4 品质各 1 张（工业哥特边框，中间留白给插画）
- **插画**：80 张专属卡 + 30+ 张遗物卡需要插画——**优先级低**，可先只出"卡面底框+卡背"，插画后续补
- **卡背**：1 张，蚀铁纹路+骷髅齿轮

### 4.2 英雄卡插画需求（80张插画可分批）
| 英雄 | 插画元素 | 张数 |
|---|---|---|
| 沃里克 | 盾/锤/列车/咆哮/残喘 | 20（5谱系×4品质） |
| 摩根 | 断头刀/血/钩链/凝视/狂欢 | 20 |
| 塞拉芬娜 | 钟/圣歌/铃/弥撒/毁灭 | 20 |
| 奥瑞斯 | 星/标记/相位/陨落/禁书 | 20 |

> 建议：品质差异用"色调+光效"区分（白=素、绿=微光、蓝=辉光、橙=燃烧），同一谱系 4 品质可共用一个构图改色调，工作量降至 20 张插画。
